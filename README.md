# Канбан на 3 месяца

Одностраничное приложение для личного планирования целей, проектов, задач и сроков.

## Возможности

- `index.html` — интерфейс приложения, стили и клиентский JavaScript.
- `api.php` — серверная авторизация и API хранения данных.
- Канбан-доска с недельной историей статусов и отдельной колонкой выполненного за выбранную неделю.
- Направления, проекты и задачи; задачи можно отправлять на канбан.
- Самостоятельные цели можно привязывать к проектам.
- Недельный светофор и заметки: одна случайная рекомендация, постоянные напоминания и пользовательские заметки.
- Дедлайны с календарём по месяцам и неделям, сортировкой по сроку и цветным приоритетом.
- Отчёт о выполненных задачах с CSV-выгрузкой.
- Печать канбан-доски и выбранного периода дедлайнов.
- Светлая и тёмная темы, адаптация под мобильные устройства и iPhone.

## Серверное хранение и вход

Данные канбана сохраняются на хостинге через PHP API, а не в `localStorage`. Все пользователи, вошедшие с одним паролем, видят одну общую доску. Сессия входа действует до закрытия браузерной сессии.

При первом входе приложение один раз переносит существующее состояние из `localStorage` этого браузера в серверное хранилище. После успешного переноса локальная копия удаляется. Последующие изменения записываются на сервер.

Для защиты создайте на хостинге файл `kanban-private/config.php`. Он содержит только хеш пароля и **не включается в публичный Git-репозиторий**. Для него в репозитории есть `.gitignore` и ограничение доступа через `kanban-private/.htaccess`.

Серверный JSON-файл автоматически создаётся PHP API в каталоге рядом с корневой папкой сайта, то есть вне публичного каталога сайта. Резервную копию данных периодически создавайте кнопкой «Экспорт».

## Ручная установка на REG.RU

В корневой каталог сайта загрузите и замените:

1. `index.html`
2. `api.php`
3. каталог `kanban-private/` вместе с файлами `.htaccess` и `index.php`

Отдельно создайте каталог `kanban-private` и загрузите в него полученный приватным способом файл `config.php`. Не загружайте его в GitHub и не публикуйте ссылку на него.

На хостинге должен быть включён PHP 7.3 или новее. Каталог на уровень выше корневой папки сайта должен быть доступен PHP для создания закрытого хранилища данных. API отклоняет входящие запросы по обычному HTTP: открывай сайт по HTTPS. При первой проверке откройте сайт по HTTPS, введите пароль и убедитесь, что доска загрузилась. После этого проверьте создание тестовой заметки, обновите страницу и убедитесь, что заметка осталась.

## Разработка

Для локального запуска с серверным хранением нужен PHP и файл `kanban-private/config.php`. Простое открытие `index.html` как файла больше не поддерживает сохранение данных.

## Безопасность

- Репозиторий публичный: не помещайте в него пароли, хеши паролей, приватные ключи и персональные данные.
- Файл `kanban-private/config.php` исключён из Git.
- Пароль проверяется сервером через `password_verify`, браузер получает только результат проверки.
- Сессионная cookie имеет флаги Secure, HttpOnly и SameSite=Strict.
- Все, кто знает общий пароль, имеют доступ к общей доске. Это простой парольный барьер, а не система индивидуальных учётных записей.
