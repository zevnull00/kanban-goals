# Канбан на 3 месяца

Автономное одностраничное приложение для личного планирования целей, проектов, задач и сроков.

## Возможности

- `index.html` — весь интерфейс, CSS и JavaScript в одном файле.
- Канбан-доска с недельной историей статусов и отдельной колонкой выполненного за выбранную неделю.
- Направления, проекты и задачи; задачи можно отправлять на канбан.
- Самостоятельные цели можно привязывать к проектам.
- Недельный светофор и заметки: одна случайная рекомендация, постоянные напоминания и пользовательские заметки.
- Дедлайны с календарём по месяцам и неделям, сортировкой по сроку и цветным приоритетом: красный — высокий, жёлтый — средний.
- Дедлайн можно добавить в проект как задачу или отправить на канбан-доску.
- Отчёт о выполненных задачах с CSV-выгрузкой.
- Печать канбан-доски и выбранного периода дедлайнов.
- Светлая и тёмная темы, адаптация под мобильные устройства и iPhone.
- Данные хранятся в `localStorage` браузера. Для переноса между устройствами используйте экспорт/импорт JSON.
- Внешние библиотеки и CDN не требуются.

## Разработка

Откройте `index.html` в браузере или разместите его в корневой директории статического сайта.

## Ручная публикация на REG.RU через GitHub Actions

Workflow находится в `.github/workflows/deploy-reg-ru.yml`. Он запускается только вручную (Actions → Deploy to REG.RU → Run workflow) и загружает только `index.html`. Удалённые файлы не удаляются.

Для запуска нужны Repository secrets:

- `REG_SFTP_HOST` — SFTP hostname или IP.
- `REG_SFTP_PORT` — порт SFTP, обычно `22`.
- `REG_SFTP_USER` — пользователь SFTP.
- `REG_SFTP_PASSWORD` — пароль SFTP.
- `REG_SFTP_KNOWN_HOSTS` — проверенная запись SSH host key для сервера.

В поле `remote_path` при ручном запуске укажите абсолютный путь к целевой директории с точки зрения SFTP. До подтверждения точного пути и проверки доступа боевой сайт не публикуйте.

Workflow сначала загружает файл под временным именем, затем переименовывает прежний `index.html` в резервный файл и переключает новый файл на имя `index.html`. Никакие другие удалённые файлы workflow не удаляет.

## Безопасность

- Не добавляйте пароли, приватные ключи или содержимое `.env` в репозиторий.
- Репозиторий публичный: исходный код приложения доступен всем.
- Не храните личные данные в исходном коде. Пользовательские цели, проекты и дедлайны остаются в хранилище браузера.
